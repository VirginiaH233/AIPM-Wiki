# Vibe Coding 工具盘点与选型(2026 年中)

## 先立一个规矩:这只是 2026-07 的一张快照

Vibe Coding 工具这个赛道,大概是整个 AI 应用领域里迭代最快的分支之一——上个月还在对比价格的两家公司,这个月可能已经改了计费模式甚至合并了功能。本文所有工具名称、定位、价格均通过 2026 年 7 月的公开信息(官网定价页为主)核实并标注访问时间,但**请把这篇文章当成"分类思路和大致门槛"的参考,具体价格和功能务必以你打开工具官网那一刻看到的为准**。如果你读到这篇文章时已经是几个月后,建议直接跳到"决策表"那一节,再自己去对应官网核实最新信息。

如果你还不清楚"Vibe Coding 是什么、AI PM 该不该自己写代码",建议先读 [Vibe Coding 是什么](what-is-vibe-coding.md)。这篇文章只聚焦"选哪个工具"。

## 三类工具,对应三种不同的"做 Demo"需求

AI PM 说"我想做个 Demo"时,其实可能是三件完全不同的事:

1. 我想让别人**看到并点一点**一个交互界面,判断这个流程顺不顺——这时候你需要的是**能生成网页应用的平台**。
2. 我想验证**一条 AI 能力/自动化流程是否成立**,比如"用户提交工单后能不能自动分类并生成回复草稿"——这时候你未必需要一个完整的网页应用,更需要**工作流搭建平台**。
3. 我已经有一定代码基础,或者需要深度参与已有代码库的调试和协作——这时候你需要的是**嵌在终端或 IDE 里的编程 Agent**。

下面按这三类分别盘点。

## 一、终端 / IDE 内的 AI 编程 Agent

这一类工具的共同点是:它们操作的是**真实代码库**,通常需要你打开一个终端或代码编辑器,门槛比后面两类略高,但上限也更高——理论上能做的事和专业工程师用的工具没有本质区别。

| 工具 | 定位 | 适合场景 | 门槛 / 大致定价(2026-07) |
|------|------|----------|----------------------------|
| **Claude Code**(Anthropic) | 终端原生的编程 Agent,强调审批优先——每一步改动、每一条命令都可以设置成需要你确认再执行,可读写整个代码库、直接执行命令 | 需要深度定制、想对每一步改动保持可控感的场景;逐渐也提供网页版和桌面端 | 随 Claude 订阅:Pro 约 $17-20/月,Max 版 $100 起(更高用量),Team Premium 席位约 $100/月起;有免费额度可先体验 |
| **Cursor** | AI 原生代码编辑器(基于 VS Code 分支),图形化界面,擅长在大代码库里做智能补全和 Agent 模式改代码 | 想要"看得见代码、边看边改"的图形化体验,而不是纯命令行 | Hobby 免费版功能有限;Pro 约 $20/月起,Pro+ 约 $60/月,Ultra 约 $200/月;Teams 约 $40/人/月 |
| **GitHub Copilot** | 深度嵌入 GitHub 和 VS Code 生态的编程助手,插件形态,和代码托管、Pull Request 流程一体化 | 团队本身已经用 GitHub 协作,PM 想在同一套工具链里改代码、发起 PR | Free 版有限额度;Pro 约 $10/月,Pro+ 约 $39/月,Max 约 $100/月(2026 年 6 月起改为额度制计费,超额需另购) |

这一类工具对完全零代码基础的 PM 来说,启动成本会比第二类平台高一些——你至少要能大致看懂终端里滚动的日志、知道"报错"和"运行成功"长什么样。但如果你已经能读一点代码,或者要长期和工程师协作在同一个代码库上迭代,这类工具的天花板明显更高。

## 二、全栈网页应用生成平台

这一类工具的共同特点是:打开网页,用对话的方式描述你要什么,平台直接生成一个能运行、甚至能拿到公开链接分享的网页应用,不需要你接触终端。这是目前对"零代码基础 PM"最友好的一类。

| 工具 | 定位 | 适合场景 | 门槛 / 大致定价(2026-07) |
|------|------|----------|----------------------------|
| **v0**(Vercel) | 对话生成前端页面和组件,底层用 React + Tailwind CSS + shadcn/ui,以生成高质量 UI 见长;2026 年 2 月起新增全栈沙箱运行时和数据库连接能力 | 想快速出一版视觉和交互都过得去的界面原型,给设计或用户做评审 | Free 版每月约 $5 额度;Premium 约 $20/月;Team 约 $30/人/月;Business 约 $100/人/月 |
| **Bolt**(StackBlitz) | 浏览器内一句话生成可运行的全栈应用,内置数据库、部署,能对接 Supabase、Stripe、Netlify、GitHub 等第三方服务 | 想要一个"从零到能跑起来"的完整小应用,不只是前端界面 | Free 版每月 100 万 token(每日上限 30 万);Pro 约 $25/月起(1000 万 token);Teams 约 $30/人/月 |
| **Lovable** | 定位为对话式"AI 软件工程师",强调完全不懂技术的人也能独立把想法做成一个可用的 Web 应用 | 完全零代码背景的 PM,想独立从零搭出一个可演示、甚至可小范围试用的产品雏形 | Free 版每日 5 点、每月约 30 点构建额度;Pro 约 $25/月;Business 约 $50/月;Enterprise 定制 |
| **Replit Agent** | 云端 IDE + Agent 一体化,能自主调试报错、写测试、管理数据库、直接部署上线,按任务复杂度计费("effort-based pricing") | 想要"做完当场就有个线上地址可以发给别人"的完整体验 | Starter 免费版有每日额度限制;Core 约 $17/月(年付)另加约 $20 用量额度;团队版 Pro 约 $100/月起 |

这四个工具的差异主要在于"前端精致度 vs 全栈完整度"的取舍:v0 在 UI 生成质量上口碑最好,但早期偏前端;Bolt、Replit Agent、Lovable 都主打"从想法到能跑起来的完整应用",适合你需要一个带数据库、能交互的真实产品雏形,而不只是一张能点的界面图。

## 三、低代码 / 工作流搭建平台

这一类和前两类最大的区别是:**它验证的不是"一个应用",而是"一条流程或一个 AI 能力是否成立"**。你不需要设计界面,而是把多个步骤(接收输入、调用模型、调用工具、输出结果)像搭积木一样连起来。这也是 [05-resources/tools.md](../../05-resources/tools.md) 中"工作流 / Agent 搭建平台"一节对应的品类。

| 工具 | 定位 | 适合场景 | 门槛 / 大致定价(2026-07) |
|------|------|----------|----------------------------|
| **n8n** | 节点式可视化工作流自动化平台,开源、可自托管,擅长把不同工具和 API(包括 AI 模型)串联成自动化流程 | 验证"一个自动化流程是否 work",比如工单自动分类、内容自动摘要并推送 | 社区版自托管免费(需自备服务器);Cloud Starter 约 €20/月(年付);Cloud Pro 约 €50/月;自托管 Business 版约 €667/月;Enterprise 定制 |
| **Dify** | 面向 LLM 应用的开发平台,内置 RAG 检索管道、Agent 编排、Prompt 管理和可视化工作流编辑器,偏"搭建一个 AI 应用的后端逻辑" | 想验证一个问答机器人、RAG 知识库或 Agent 的产品逻辑是否成立,不需要自己写前端界面 | Sandbox 免费版每月 200 条消息额度;Professional 约 $590/年;Team 约 $1590/年;Enterprise 定制;另提供开源自托管版本 |
| **Coze(扣子)**(字节跳动) | 国内主流的智能体 / 工作流搭建平台,可视化搭建 Agent 并一键发布到飞书、微信、网页等多渠道;2026 年新增"扣子编程",定位为面向 Vibe Coding 的基础设施 | 中文语境下想快速搭一个能对外发布的智能体或自动化流程,不追求代码级定制 | 个人免费版仍保留;个人高级版自 2026 年 3 月起约 39.9 元/月;企业版按坐席/资源点计价,新定价自 2026-07-13 生效 |

n8n 偏"通用自动化",几乎任何软件都能接入,适合"把 AI 能力嵌进已有工具链"这种场景;Dify 偏"AI 应用本身",更适合验证一个对话机器人或知识库问答的产品逻辑;Coze 的优势是中文生态和多渠道发布(尤其是飞书、微信),如果你的目标用户在这些渠道,启动会更快。

## PM 该选哪一类:按"我要验证什么"分流

与其纠结"哪个工具最好",不如先问自己一个问题:**这次我要验证的核心不确定性是什么?**

| 我要验证的是… | 推荐工具类别 | 理由 |
|----------------|--------------|------|
| 这个交互流程顺不顺、界面看着对不对 | 全栈应用生成平台(优先 v0,偏视觉;或 Bolt/Lovable) | 几分钟到几十分钟就能出一版可点的界面,不需要懂代码 |
| 这是不是一个能真正跑起来、能分享链接的产品雏形(有数据、有基本逻辑) | 全栈应用生成平台(Bolt / Replit Agent / Lovable) | 这三者都内置数据库和部署能力,做出来的不只是"图",是能交互的东西 |
| 一条自动化流程或 AI 能力串联是否成立(不需要界面,或界面很简单) | 工作流搭建平台(n8n / Dify / Coze) | 这类工具本身就是为"连接步骤"设计的,不用为了验证一个流程而多搭一层界面 |
| 我已有一定代码基础,要深度参与已有代码库的调试和长期迭代 | 终端/IDE 编程 Agent(Claude Code / Cursor / GitHub Copilot) | 操作的是真实代码,上限最高,也最适合和工程师在同一套工具链里协作 |
| 我的目标用户在飞书/微信生态,想尽快对外发布 | Coze | 原生支持多渠道一键发布,中文语境适配更好 |

实际工作中,这几类工具经常会组合使用:先用 Bolt 或 Lovable 快速拼出一个可点的界面原型去说服团队,方案通过后再和工程师一起用 Claude Code 或 Cursor 在正式代码库里重新实现;或者先用 n8n 验证一条自动化逻辑是否可行,再决定要不要为它单独做一个前端界面。工具是为验证目的服务的,不必执着于"一步到位选对一个"。
