# 产品设计题

"为 X 设计一个 AI 功能"类题目。考察需求分析、方案设计、技术可行性判断的综合能力。

## 答题框架(通用)

1. **澄清与界定**:目标用户是谁?解决什么问题?成功指标是什么?
2. **方案设计**:核心流程 + AI 在其中的角色(别为了 AI 而 AI)
3. **技术方案**:大概用什么架构(Prompt / RAG / 微调 / Agent),为什么
4. **风险与兜底**:模型出错时怎么办?冷启动怎么办?
5. **衡量与迭代**:上线后看什么指标,数据怎么回流

## 高频题征集中(欢迎认领投稿)

- 为微信设计一个 AI 功能
- 为电商 App 设计一个 AI 导购
- 设计一个面向老年人的 AI 产品
- 你负责一个 AI 客服产品,解决率停在 70% 上不去,怎么办?
