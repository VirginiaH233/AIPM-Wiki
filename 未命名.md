| Benchmark 名称                 | 含义说明                                                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **HLE w/o tools**            | Hardest‑LLM‑Exam，**无工具调用**高难度综合推理测试集（数学、逻辑、科学难题）。w/o tools = 模型纯靠自身知识推理，不允许调用任何工具。括号里†代表仅文本子集得分。                               |
| **Terminal‑Bench 4.0**       | Agent 终端操作基准。让模型操控 Linux 终端，执行 shell 命令、文件操作、git、编译调试等真实开发任务；版本 4.0 难度很高，**完全贴合 Hermes 这类代码 Agent 场景**。本项跑在 Claude Code 测试框架下。 |
| **DeepSWE v1.1**             | 软件工程师 Agent 基准。给真实开源仓库 + issue，Agent 读取代码、定位 bug、输出修复 patch；衡量真实代码库排错修复能力，使用 Mini‑SWE‑V2 harness。                              |
| **ProgramBench**             | 复杂多文件工程编写基准，考验复杂 API 调用、多模块程序构建，偏向大型工程代码生成。                                                                                    |
| **NL2Repo‑Bench**            | Natural‑Language‑to‑Repo，自然语言直接生成完整代码仓库；一句话需求输出整套项目代码。                                                                         |
| **Automation‑Bench v1.0.6**  | 通用自动化 Agent 基准：多步骤业务编排、文件处理、工具串联，偏向通用任务自动化，和 Hermes 工作流高度相关。                                                                   |
| **Agents’ Last Exam**        | Agent 综合终极考试，混合工具调用、多轮长任务、推理、多模态，整体难度很高。                                                                                       |
| **Apex Bench v1.1**          | 高难度数学推理基准，竞赛级多步数学解题。                                                                                                           |
| **Chartography (w/tools)**   | 带工具调用的图表理解任务：读取图表、数据分析、推理；`(w/tools)`代表允许启用工具。                                                                                 |
| **BabyVision (w/tools)**     | 多模态 Agent 基础任务：识图、OCR、图文推理，允许调用工具。                                                                                             |
| **ZeroBench‑main (w/tools)** | 零样本多模态 Agent，考察模型对从未见过的图文任务的泛化能力，允许工具调用。                                                                                       |
